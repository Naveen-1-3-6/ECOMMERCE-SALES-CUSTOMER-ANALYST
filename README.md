# 🛒 E-Commerce Sales & Customer Analytics Dashboard

## 📊 Project Overview

**E-Commerce Sales & Customer Analytics** is an interactive **Power BI dashboard** designed to analyze e-commerce business performance and provide insights into **sales, profit, customers, orders, operations, and marketing**.

The dashboard transforms raw business data into meaningful visualizations and KPIs, helping users understand sales trends, customer behavior, product performance, and overall business performance.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze overall e-commerce sales performance.
* Track **Sales, Profit, Orders, and Customers**.
* Identify profitable and underperforming products.
* Understand customer purchasing behavior.
* Analyze sales trends over time.
* Monitor operational performance.
* Provide interactive filtering and drill-down capabilities.
* Create an easy-to-use business intelligence dashboard.

---

## 📐 Key Power BI Concepts Used

### Power Query

Power Query was used to:

* Clean the raw dataset
* Handle missing values
* Remove unnecessary columns
* Transform data types
* Create usable tables
* Prepare data for analysis

### DAX

DAX was used to create calculated measures and KPIs such as:

* Total Sales
* Total Profit
* Total Orders
* Total Customers
* Profit Margin
* Average Order Value
* Sales and profit comparisons

### Data Modeling

A structured data model was created to establish relationships between relevant tables and support efficient analysis.

## 🚀 How to Use the Project

1. Download or clone this repository.
2. Install **Microsoft Power BI Desktop**.
3. Open:

```text
ECOMMERCE SALES CUSTOMER ANALYST.pbix
```

4. If Power BI asks for the data source, update the source path to the location of the dataset.
5. Refresh the data if required.
6. Explore the dashboard using the available filters and navigation buttons.
